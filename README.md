## 🌟 About This Project

This project is a beautiful and interactive **Happy Diwali 2026 Greeting Website**, developed using HTML, CSS and JavaScript.

The website celebrates the festival of lights with beautiful animations, glowing Diyas, fireworks and festive greetings.

It is automatically deployed using **GitHub Actions and GitHub Pages**.

## 🚀 Features

- 🪔 Beautiful Diwali greeting design
- 🎆 Animated fireworks effects
- ✨ Glowing Diya animation
- 🌈 Attractive festive background
- 📱 Responsive mobile-friendly design
- 💚 WhatsApp greeting sharing
- ⚡ Automated CI/CD deployment
- 🌐 Free hosting using GitHub Pages

## ⚙️ CI/CD Workflow

The website deployment is automated using GitHub Actions.

```text
Developer
    |
    v
GitHub Repository
    |
    v
Git Push (main)
    |
    v
GitHub Actions
    |
    v
Checkout Source Code
    |
    v
Upload Website Artifact
    |
    v
GitHub Pages Deployment
    |
    v
Website Live 🚀
```

### Deployment Process

1. Developer pushes code to the main branch.
2. GitHub Actions workflow triggers automatically.
3. Source code is checked out.
4. Website files are packaged as an artifact.
5. Artifact is deployed to GitHub Pages.
6. Website becomes publicly accessible.
