## 🌟 About the Project

A beautiful and interactive Dhanteras greeting website
created using HTML5, CSS3 and JavaScript.

Featuring golden animations, traditional Kalash,
glowing Diyas, floating coins and festive fireworks.

## 🚀 Features

- Golden festive website design
- Animated Dhanteras Kalash
- Floating gold coins
- Glowing Diyas
- Fireworks animation
- WhatsApp greeting sharing
- Mobile responsive layout
- Automated CI/CD deployment

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and animations |
| JavaScript | Interactive effects |
| GitHub | Source code management |
| GitHub Actions | CI/CD automation |

## ⚙️ CI/CD Pipeline

```text
Developer
    |
    v

    |
    v
Git Push to Main
    |
    v
GitHub Actions
    |
    v
Checkout Source Code
    |
    v
Upload Pages Artifact
    |
    v
Deploy to GitHub Pages
    |
    v
Website Live 🚀
```

## 💻 Run Locally

```bash
git clone https://github.com/Ramjish/Happy-Diwali-2026-Ramji-Sharma.git

cd Happy-Diwali-2026-Ramji-Sharma
```

Open index.html in your browser.

## 🔄 Deploy Updated Code

```bash
git add .
git commit -m "Update Dhanteras 2026 website"
git push origin main
```

GitHub Actions automatically deploys the updated website.
